# To Quick Cleanup and CLear
A Simple batch script that will clear the contents of the temp, %temp% , prefetch and recent files from your PC

#STEPS
- Save the file { cleanup_and_clear.bat } file in your desktop.
- Right click the file and select " Run as Administrator " (this ensures access to system folders like Prefetch).
- This ensures access to system folders like Prefetch
- A command prompt will open, perform the cleanup process, and pause so you can see the result.

*Important Note*
: what you're doing is mostly safe and can help keep your system tidy-just be cautious not to delete files that are actively in use.

Description:

- temp and %temp%
These store temporary files created by Windows and apps during installations, updates, or usage.
Pros---- Frees up disk space, may improve performance, and removes leftover junk.
Cons---- If you delete files still in use, it might cause apps to crash or lose unsaved data.

- prefetch
This folder helps Windows launch apps faster by storing data about how programs start.
Pros---- Can clear outdated entries and free up a bit of space.
Cons---- Slower app launch times until Windows rebuilds the data.

- recent
This shows shortcuts to recently opened files.
Pros---- Boosts privacy by hiding your activity, and declutters the Quick Access view.
Cons---- You lose quick access to files you were just working on.
